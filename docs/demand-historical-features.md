# 폐업 조기경보용 과거 수요 피처 — 연구용 v1

## 목적

카드매출로 계산한 행정동별 수요 흐름이 폐업 조기경보 성능을 실제로 높이는지
검증하기 위한 중간 산출물이다. 수요예측 결과를 현재 폐업모델에 바로 넣지 않고,
폐업모델의 각 과거 분기와 같은 시점에 알 수 있었던 수요만 복원한다.

## 생성 흐름

1. 공식 카드 업종코드가 80개 이상이고 화성시 29개 행정동이 모두 관측된 월만 사용한다.
2. 분기 말까지 3개월이 연속된 경우에만 다음 달 행정동 수요점유율을 예측한다.
3. rolling 혼합비는 해당 분기 말까지 정답이 확인된 과거 월로만 선택한다.
4. 예측 수요점유율과 같은 분기의 소진공 점포점유율을 비교한다.
5. 행정동×소진공 중분류×분기 집계 테이블로 저장한다. 개별 점포는 포함하지 않는다.

실행:

```bash
python ai/build_historical_demand_features.py
```

산출물:

- `data/processed/demand_features_historical.csv`
- `data/processed/demand_features_historical_audit.json`

## 주요 피처

| 피처 | 의미 |
|---|---|
| `예측수요점유율` | 다음 달 해당 업종의 화성시 카드수요 중 행정동 몫 |
| `현재수요점유율` | 분기 말 현재의 행정동 수요 몫 |
| `최근3개월평균수요점유율` | 연속 3개월 행정동 수요 몫 평균 |
| `수요모멘텀_3개월` | 현재 점유율 − 최근 3개월 평균 |
| `공급점유율` | 같은 분기 해당 업종 점포 중 행정동 점포 몫 |
| `공급점유율_전분기변화` | 공급 몫의 전분기 대비 변화 |
| `수요공급격차_log` | `log((예측수요점유율+ε)/(공급점유율+ε))` |
| `수요감소_공급증가_플래그` | 수요 몫은 감소하고 공급 몫은 증가한 조합 |

`수요공급격차_log`가 낮을수록 수요에 비해 공급이 많은 상태다. 이 값은 폐업의
인과 원인이 아니라, 기존 폐업모델에 추가해 성능 차이를 검증할 후보 피처다.
전분기에 해당 행정동×업종 셀이 없었던 경우 `전분기공급점유율`과 그 변화량은
결측으로 남기며 0으로 임의 대체하지 않는다.

## 시간 누수 방지

- 2022Q1 피처를 만들 때 2022년 3월 이후 카드매출을 사용하지 않는다.
- 혼합비 선택도 예측기준월까지 정답이 알려진 target month만 사용한다.
- 2024년 결측 11개월은 보간하지 않는다.
- 현재 폐업모델의 train/validation/test 경계를 유지한 채 동일 행을 비교해야 한다.

## 현재 적용 판정

최신 공식 파일도 카드매출 범위가 2018-01~2025-06이며 2024-02~2024-12가
비어 있다. 이 때문에 3개월 연속으로 생성 가능한 분기는 7개이고, 기존 폐업모델
validation 구간(2023Q3~2024Q2)에는 한 분기도 없다.

따라서 v1은 **연구용 연결 검증에는 사용 가능하지만 운영 폐업모델 피처로는 적용
불가**다. 운영 반영 전에는 최소한 다음 조건을 충족해야 한다.

- 연속 관측 기반 과거 분기 12개 이상
- 기존 validation 구간에 수요 피처 2개 분기 이상
- 결측 월 해소
- 카드 업종↔소진공 업종 매핑 검토 또는 공식 연계표 확보
- 동일 시간 분할에서 기준 모델 대비 Spearman·Top 10 lift 개선 확인
