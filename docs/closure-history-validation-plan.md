# 과거 관측 폐업률 입력 검증 계획 — 2026-09-03

아래 비교·기간·판정은 새 모델의 시험 결과를 계산하기 전에 고정한다.
목표는 시점 누수를 차단한 연구 파이프라인에서 과거 관측 이탈률의 추가 효과를
확인하는 것이다. 운영 모델·DB·점수·API는 자동 교체하지 않는다.

## 입력을 당시 정보로 복원

- 원본 SSD 폴더는 연결되지 않았지만 로컬 `store_panel.csv`에 실제 관측 행
  817,741개(`is_filled=0`)와 후처리 보정 행 55,294개가 구분되어 있다.
  보정 행을 버리고 실제 관측 행만 사용한다. 점포×분기 중복·필수 결측은 0건이다.
- 식별자·지역·업종·분기·보정 여부 다섯 열만 로컬에서 읽는다. 주소·좌표·인허가·
  기존 학습 정답·현재 수요·기존 모델 파일은 실험 입력으로 사용하지 않는다.
- 각 예측 시점 B의 입력은 B까지의 스냅샷만으로 만든다. 한 분기 빠졌다가
  돌아온 점포는 **B까지 재등장이 확인된 경우만** 중간 공백을 보정한다.
  보정 폭은 사전 고정 1분기이며 기존의 미래 자료로 선택한 11분기를 재사용하지 않는다.
  B 이후 재등장은 B의 입력을 바꾸지 못한다.
- 현재 점포 수는 B 스냅샷의 실제 관측 점포 수다. 최신 인허가를 이용한 업력은
  당시 입수 여부를 증명할 수 없으므로 두 모델 모두 **최초 관측 후 기간**으로
  대체한다. 이 값은 실제 사업 업력이 아니며 2020Q4 이전은 좌측 절단된다.
- 최근 1분기 이탈률은 같은 지역×업종의 직전 집합에서 현재 집합으로 이탈한
  수/직전 점포 수다. 최근 4분기는 이 건수합/직전 점포 수 합이다.
  두 값 모두 B까지 확인된 보정만 적용한다. 분모·연속 창 결측을 0으로 채우지 않는다.

## 정답과 시점 계약

- 정답은 B 시점의 점포가 **B+2의 전체 화성시 스냅샷에 없는 비율**이다.
  다른 지역·업종으로 이동했지만 같은 ID로 관측되는 점포는 이 정답의 이탈로 세지 않는다.
- B+2 자료가 없으면 정답은 NaN이다. B+3 이후 재등장으로 정답을 소급 수정하지 않는다.
  따라서 실제 폐업 확정이 아닌 **2분기 뒤 스냅샷 미관측률**이다.
  원자료 누락·ID 변경을 실제 폐업과 완전히 구별할 수 없다는 한계를 유지한다.
- 각 행에 입력 최종 시점과 정답 확인 가능 분기를 기록한다. 학습 정답 완성 시점은
  validation 입력 시작보다 앞서고, validation 정답 완성 시점은 test 입력 시작보다
  앞서도록 분리한다. 카테고리 목록도 학습 집합에서만 확정한다.
- 분기는 스냅샷 순서를 뜻한다. 실제 발행/입수일의 원장까지 확보한 것은 아니다.
  예를 들어 2025Q3 자료는 10월 발간 자료로 매핑된 기록이 있다. 결과를 정확한
  달력상의 배포 성능이라고 주장하지 않는다.

## 고정 비교

| 모델 | 입력 |
|---|---|
| 시점 제한 입력 기준 모델 | 읍면동·업종·현재 점포 수·최초 관측 후 평균 기간 |
| 과거 이탈률 추가 모델 | 동일 입력 + 최근 1분기 이탈률 + 최근 4분기 이탈률 |
| 관측 순위 기준선 | 최근 4분기 이탈률만으로 정렬; 순위 지표만 비교 |

두 LightGBM은 같은 행·설정·시간 분할로 다시 학습한다. 저장된 운영 모델과
새 모델의 숫자를 직접 비교하면 전처리·업력·정답까지 달라지므로 그렇게 하지 않는다.
기존 설정 계열(회귀, 최대 1,000회, learning_rate .05, num_leaves 31,
min_child_samples 20)을 고정하고 validation으로만 early stopping 50을 적용한다.
하이퍼파라미터 탐색이나 test 결과를 본 뒤 입력 조합 변경은 하지 않는다.
두 모델의 평가 예측은 같은 방식으로 0~1에 제한한다.

- 학습 입력: 2021Q4~2022Q4(정답은 늦어도 2023Q2에 완성)
- validation 입력: 2023Q3~2023Q4(정답은 늦어도 2024Q2에 완성)
- test 입력: 2024Q3~2025Q2(정답은 늦어도 2025Q4에 완성)
- 주 시험 시점: **2024Q3·2025Q1**. 이후 두 분기 창이 서로 겹치지 않는다.
- 보조 시점: 2024Q4·2025Q2. 매 분기 동작을 확인하되 독립된 반복 시험으로 세지 않는다.
- 점포 30곳 이상, 같은 과거 4분기 입력 확보 행으로 공통 모집단을 만든다.
  정답 없는 최신 두 분기는 학습/평가에서 제외하되 별도 추론은 가능하다.

## 지표와 판정

각 분기 Spearman(높은 위험 순위), 예측 상위 10%의 실제 정답률/전체 평균(lift),
MAE를 비교한다. 상위 10%는 `prediction >= quantile(.9)`이며 동점 포함 수를 보고한다.
순위 상관과 lift는 분기별 동일 가중 평균을 주 요약으로 삼고, 지역 단위 paired
bootstrap 1,000회(seed 42)로 같은 셀·시점의 모델 차이를 비교한다.
모델 절대 예측값은 메모리에서만 평가하고 외부 결과에는 집계 성능만 기록한다.

다음 모두를 만족하면 연구용 추가 효과가 있다고 표시한다:

1. 두 주 시험 시점 모두 Spearman과 lift가 기준 모델보다 높다.
2. 주 시험 평균 MAE가 악화되지 않는다.
3. Spearman 차이와 lift 차이의 지역 bootstrap 95% 구간 하한이 0보다 크다.

이 조건을 통과해도 운영 자동 교체는 하지 않는다. 동일 자료가 이전 분석에서
반복 사용됐고, 실제 폐업 정답/스냅샷 누락/발행일 원장/업력 대체의 문제가 남는다.
2023Q1 등 알려진 데이터 결함 시점을 유리한 결과를 얻기 위해 사후 제외하지 않는다.
한정된 주 시험 2회는 새로운 외부 미사용 기간을 대체하지 못한다.

검증 코드는 미래 행 추가·변조 불변성, 미래 재등장에 의한 소급 보정 방지,
정답 완성 시점 분리, 결측·중복·분기 누락, 이동 점포 처리, 학습 카테고리 고정을
합성 데이터로 확인한다. 연구 산출물은 무시 경로에 저장하고 코드·집계 보고서만 커밋한다.
