# 인허가 폐업일 기반 정답 검증 계획

2026-09-03. 원본 연결·성능 결과를 계산하기 전에 고정한 연구 계획.

## 목적과 범위

소진공 B 시점 점포가 B+2에 명단에서 사라졌다는 대리지표를 인허가에 기록된
폐업일과 대조한다. 같은 점포·같은 셀·같은 기간에서 정답만 바꾼 연구 모델을
비교한다. 운영 모델·추천 산식·DB를 갱신하지 않는다. 일반 교육은 현 파일에
폐원 이력이 없으므로 대상이 아니다. 인허가 12종도 업종 대응이 명확한 경우만 연결한다.

## 연결 및 정답

- 원본 21개 분기에서 상호명·지점명·주소·층/호·업종을 복원한다. 소진공 점포번호는
  같은 분기 식별 및 B+2 도시 전체 존재 여부에만 사용한다.
- 상호명(또는 상호명+지점명) 완전일치와 도로명 건물주소/지번주소 일치를 함께 요구한다.
  공백·문장부호·유니코드 표기와 화성시의 새 구 이름만 정규화한다. 유사문자열 매칭은 하지 않는다.
  주소의 층/호는 두 자료에 모두 있으면 일치를 요구한다. 건물주소만 맞고 상호명이 다른 후보는 제외한다.
- 인허가 종류와 소진공 업종 대응을 검사한다. 음식점은 음식 업종, 미용/이용은 이용·미용,
  세탁은 세탁 등 명확한 대응만 허용한다. 약국·PC방·노래방·헬스장·제과점은 소분류도 확인한다.
- 인허가 시작일이 B보다 늦거나 폐업일이 B 이전/당일이면 B의 위험집단에서 제외한다.
  복수 인허가 후보와 동일 분기 여러 점포가 같은 인허가로 연결되는 경우 모두 보류한다.
  폐업 이후 재등장을 보고 매칭이나 학습 표본을 사후 변경하지 않는다.
- 인허가 정답은 B 이후 B+2 분기말까지 명시적 폐업일자가 있는 경우 1이다.
  폐업 상태·날짜가 모순되거나 휴업/취소/말소/재개업 흔적이 있으면 미확인으로 남긴다.
  0은 종료일이 B+2보다 늦은 폐업 기록 또는 현재 영업/정상이며 폐업일이 없고
  자료 갱신 시점이 B+2 이후인 기록에서만 부여한다. 이것도 행정 기록상의 비폐업이며
  현장 확인된 존속은 아니다. 연결 실패·정답 미확인은 0으로 채우지 않는다.
- B+2 스냅샷이 없거나 행정자료 추적 시점이 부족하면 비교 정답을 만들지 않는다.
  현재 인허가 자료는 당시 버전이 없어 날짜 기준 회고적 정답이다. 실제 당시 입수 가능한
  학습 정답이었다고 주장하지 않는다. 미래 폐업일·현재 영업상태는 모델 입력에 넣지 않는다.

## 비교 설계

- 기존 시점 제한 실험과 같은 학습(2021Q4~2022Q4), 검증(2023Q3/Q4),
  시험(2024Q3~2025Q2)을 고정한다. 주 시험은 결과 창이 겹치지 않는 2024Q3·2025Q1이다.
  이미 반복 분석한 기간이므로 새로운 독립 검증으로 부르지 않는다.
- 입력은 `SnapshotHistory.features_at(B)`의 지역·업종·점포수·최초 관측 후 기간·
  최근 1/4분기 관측 이탈률이다. 두 모델의 입력과 행을 완전히 동일하게 한다.
- 셀은 전체 점포 30개 이상, 연결·정답 확인 점포 30개 이상, 확인 비율 50% 이상으로 제한한다.
  양쪽 정답의 분모는 동일한 확인 점포 집합이다. 완전한 과거 입력이 없는 셀은 제외한다.
  학습 100셀, 검증 및 주 시험 각 분기 20셀 미만이면 성능 비교를 중단하고 커버리지 한계를 보고한다.
- 같은 LightGBM 설정(최대 1,000회, 학습률 .05, 잎 31, 최소 표본 20, seed 42,
  CPU 2개)을 사용한다. 학습 정답만 미관측률/인허가 폐업률로 바꾸고 조기종료는
  두 모델 모두 검증 구간의 인허가 폐업률 기준으로 50회 대기한다.
- 두 모델 모두 시험 구간의 인허가 폐업률에 대해 평가한다. 분기별 Spearman,
  상위 10% lift, MAE(%p), 선정 수를 기록한다. 동점은 모두 포함한다.
  지역 클러스터 bootstrap 1,000회로 주 시험 분기 평균 차이의 95% 구간을 제시한다.
  표본·분모·정답이 달라 기존 운영 성능 수치와 직접 비교하지 않는다.
- 두 주 시험에서 순위와 lift가 모두 개선되고 차이 구간 하한이 0보다 크며 MAE가
  악화되지 않을 때만 개선 신호로 판단한다. 이 기준을 통과해도 매칭 정확도의 독립 확인,
  당시 자료 버전·갱신 지연 및 새 시험 기간이 없으므로 운영 채택은 별도 검증이 필요하다.

## 검증 및 산출물

합성 자료로 동명이업체·빈 이름/주소·층/호 충돌·복수 허가·시기 불일치·휴업/취소·
정답 성숙·미매칭 결측·같은 분모·미래 입력 불변성을 검증한다. 실제 원본과 로컬 관측
패널의 키·업종·분기 일치를 확인한다. 매칭 단계별 탈락, 업종별 커버리지, 2×2 정답
불일치표와 폐업일 이후 재등장은 집계로만 보고한다. 재등장 진단으로 모델을 다시 고르지 않는다.

코드·계획·집계 보고서는 저장소에 둔다. 식별자·원본·연결표·연구 모델은
`data/processed/permit_label_audit/`에만 저장하며 커밋하지 않는다. 외부 전송 없이 로컬 처리한다.
