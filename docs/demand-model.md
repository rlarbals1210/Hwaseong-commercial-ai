# 상권둘러보기 수요 예측 모델

## 1. 목적

`상권둘러보기`의 추천이 폐업 부담·점포 수·포화도만 보던 한계를 보완한다. 공개
카드매출로 **다음 달 업종별 지역 수요점유율**을 예측하고, 최신 점포 수로 계산한
**지역 공급점유율**과 비교해 `수요 여건` 축을 만든다.

예측 금액이나 특정 점포의 성공확률은 API에 공개하지 않는다. 화면에는 같은 업종의
화성시 읍면동 안에서 정규화한 0~100 상대점수만 표시한다.

## 3. 왜 매출액 대신 점유율을 예측하는가

카드매출은 구코드와 신코드의 집계 범위가 달라 전환 시점에 절대금액이 끊긴다. 반면
같은 카드 업종의 화성시 전체 매출 중 각 행정동이 차지하는 비중은 스케일 변화에 덜
민감하다. 따라서 타깃을 아래처럼 정의했다.

```text
행정동 수요점유율 = 해당 행정동·카드업종 매출 / 화성시 해당 카드업종 전체 매출
```

신코드가 80개 이상이고 현재 29개 행정동이 모두 관측된 월만 사용한다. 원본이 없는
2024-02~2024-12는 보간하지 않고 학습에서 제외한다.

## 4. 시간 분할과 모델 선택

무작위 분할을 쓰지 않는다.

| 구간 | 예측 대상 월 | 행 수 |
|---|---|---:|
| 학습 | 2022-02~2022-12의 연속 관측 7개월 | 16,849 |
| 검증 | 2023-01~2023-07 | 16,849 |
| 최종 시험 | 2025-02~2025-06 | 12,035 |

검증 구간에서 다음 후보를 비교했다.

1. 직전월 점유율 유지(기준선)
2. 직전월과 최근 3개월 평균의 혼합
3. LightGBM과 직전월 기준선의 혼합

선택 결과는 `직전월 40% + 최근 3개월 평균 60%`다. LightGBM보다 단순 시계열
평활 모델이 검증 MAE가 낮았다. 복잡한 모델을 썼다는 이유만으로 채택하지 않았다.

최종 시험 결과:

| 지표 | 직전월 기준선 | 선택 모델 | 변화 |
|---|---:|---:|---:|
| MAE | 0.008380 | 0.008074 | **3.65% 개선** |
| 월·업종별 평균 Spearman | 0.9309 | 0.9334 | +0.0025 |
| 상위 5개 동 평균 일치율 | 0.8708 | 0.8733 | +0.0024 |

MAE 0.5% 이상 개선, 순위상관·상위 5개 일치율 비열화 기준을 모두 통과했을 때만
추천 로직이 `demand_scores.csv`를 읽도록 했다. 검증 실패 시 `검증통과=False`가 되어
수요 축은 자동으로 50점(중립)으로 남는다.

## 5. 수요와 공급 비교

소진공 중분류 74개를 공식 카드 중분류 명칭과 대조해 83개 카드코드에 연결한다.
예측한 코드별 지역 점유율을 최근 3개월 화성시 업종 규모로 가중한 뒤, 선택한 소진공
업종의 지역 점포 비중과 비교한다.

```text
수요공급격차 = log((예측 수요점유율 + ε) / (현재 점포점유율 + ε))
```

이 격차가 클수록 `수요 여건` 점수가 높다. 매출 규모가 큰 동을 무조건 추천하는 게
아니라, 그 업종의 예상 수요 비중에 비해 현재 점포 공급이 상대적으로 적은 곳을 찾는다.

## 6. 추천점수 반영

기본 `균형` 프리셋은 다음 네 축을 쓴다.

| 축 | 가중치 |
|---|---:|
| 폐업 부담의 반대값(`성장 추세`) | 35% |
| 예측 수요와 현재 공급의 격차(`수요 여건`) | 30% |
| 동종업종 점포 수의 반대값(`경쟁 우위`) | 20% |
| 읍면동 내 업종 비중의 반대값(`포화도`) | 15% |

`수요 여건 좋게` 프리셋은 수요 축을 60%로 높인다. 모든 축은 같은 업종의 읍면동
안에서 0~100으로 정규화하며, 점포 50곳 미만은 기존 방식대로 50점 쪽으로 보정한다.

## 7. 한계

- 최신 카드매출은 2025-06까지라 예측 대상은 2025-07이고, 2025Q4 점포 공급과 시차가 있다.
- 카드 업종과 소진공 업종의 공식 일대일 대응표는 없어 명칭 기반 프록시 매핑이다.
- 점수는 절대 매출액이나 창업 성공확률이 아니라 지역 간 상대 수요·공급 격차다.
- 카드로 포착되지 않는 현금 소비, 임대료, 접근성, 예정 개발은 현장 확인이 필요하다.
