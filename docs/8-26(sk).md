## 2. 첫 덩어리 — 계산·데이터 감사에서 고친 6건

### (1) 현장 확인 우선순위 — 3중 결함

**CSV의 등급 열이 전 행 "안정"으로 나가고 있었습니다.** 위험 24셀·주의 46셀까지 전부요.
`PolicyPriorityItem`에 `risk_grade`를 안 넘겨 스키마 기본값이 그대로 실렸습니다.
폐업건수 열은 전 행 0, 상권유형 열은 전 행 빈칸이었습니다.

**화면의 폐업률이 단일 분기였습니다.** 라벨은 "최근 1년"인데요.
위험 24셀 중 **19셀이 화성시 평균(5.9%)보다 낮은 숫자로** 표시되고 있었습니다.

**사분면 문구가 실제 규칙과 달랐습니다.** x축은 중위값이 아니라 등급(상위 10%)인데
화면은 "중위값 아래"라고 안내해서 주의 등급 46셀이 안전해 보였습니다.

### (2) NULL이 0.0%로 둔갑

`(value or 0.0) * 100` 때문에 값이 없는 구간이 "폐업 0%"로 그려졌습니다.
**전체 35,505행 중 7,466행(21%)** 이 해당합니다. 누적값은 4분기가 쌓여야 나오므로
앞 구간은 원래 값이 없는 게 맞습니다.

### (3) 분모 불일치

셀 상세가 `16.04%` 아래에 `"47곳 닫힘 / 전체 53곳"`(89%)을 병기했습니다.
누적 폐업률의 분모는 **4개 분기 직전점포수의 합**(293)이지 현재 점포수(53)가 아닙니다.
표본충분 231셀 전부 해당, 배율 중위 4.14배.

### (4) 커버율 0%인 읍면동이 초록(안정)

분모 0 → 비율 0.0 → "안정". **판단 불가가 안전으로 읽히고 있었습니다.**

### (5) 읍면동 등급의 분모가 3~6셀

29개 중 19개가 표본충분 셀 10개 미만. 지도에서 **가장 빨간 두 곳이
동탄8동 2/3(66.7%), 새솔동 4/6(66.7%)** 이었습니다.

→ **표본충분 5개 미만 = 판단보류(회색), 5~9개 = 등급은 내되 흐리게.**
색은 등급, 진하기는 근거의 두께입니다.

### (6) 무인증으로 예측값이 나가고 있었습니다

`/api/analysis/*` 5개만 인증 가드가 없었고, `/score`가 `grade`·`predicted_rank`·
`top_percent`를 반환했습니다 — `public.py`가 "예측값 계열은 어떤 형태로도 내지 않는다"고
못박은 항목입니다.

## 3. 둘째 덩어리 — 화면 감사에서 고친 것

> 담당자의 다음 행동이 그 자리에서 끊깁니다.

API limit인데 첫 화면 첫 타일에 32px로 떴습니다. **실제로는 1,802개를 분석했고
231개가 판정 가능합니다.** 자기 강점을 스스로 깎아먹는 라벨이었습니다.

이제 "예측 상위 10개 상권"이고, 아래에 모수를 밝힙니다. 231이라는 숫자는

두 화면의 1순위가 다른 이유가 도착지에 없었습니다.

> 이 화면은 **이미 관측된** 폐업률로 줄을 세웁니다. 조기경보 대시보드는 모델이 예측한
> **2분기 뒤** 위험으로 줄을 세웁니다. 두 화면의 1순위는 다를 수 있으며, 다른 것이 정상입니다.

### 사각지대 → 셀 상세에서 경고가 살아났습니다

`CellDetailPage`가 `sample_insufficient`를 한 번도 쓰지 않았습니다.
사각지대에서 "폐업률을 판단 근거로 쓰지 마세요"라고 해놓고, 링크 타면
점포 12곳짜리의 16.7%가 38px로 떴습니다.

이제 표본부족 셀은 **대표 숫자가 폐업률 → 건수**로 바뀌고, 비교 막대가 숨겨지고,
상단에 경고 배너가 붙습니다.

## 4. 코드를 만지는 사람 — Breaking Change

### 응답 필드가 Optional이 됐습니다

```
ClosureRiskItem / ClosureRateRankingItem / BlindspotItem / CompareCellItem
  cumulative_closure_rate_pct   float → float | None
  closure_rate_pct              float → float | None
  confidence_lower_pct          float → float | None
  quarter_closure_rate_pct      float → float | None
  open_rate_pct                 float → float | None
```

누적 지표는 4분기가 쌓여야 나옵니다. 없는 값을 0.0으로 채우면 "판단 불가"가
"가장 안전"으로 읽힙니다. 프론트는 전부 `fmt()`를 거쳐 "—"로 그립니다.

### 신규 필드

```
GET /api/policy/inspection-priority
  area_id / industry_id                신규. 셀 상세 링크용
  risk_grade / cell_type / cumulative_closure_count   이제 실제로 채워짐
  actual_closure_rate_pct              단일 분기 → 4분기 누적 (값이 커집니다)

GET /api/alerts/closure-rate-ranking
  area_id / industry_id                신규

GET /api/alerts/vacancy-risk/map
  risk_ratio        float → float | null    판단보류는 null
  risk_level        "판단보류" 값 추가
  evidence_thin     신규 bool               표본충분 5~9개면 true
  hold_notice       신규 str | null

GET /api/alerts/grade-notice
  eligible_cells    신규 int                기준선 산출 모수(231)

GET /api/cells/{a}/{i}
  cumulative_denominator   신규 int | null   누적 폐업률의 실제 분모
  denominator_estimated    신규 bool

GET /api/analysis/*
  인증 필요. 토큰 없이 부르면 401/403
```

### `_pct` 사본을 만들지 마세요

`backend/services/risk.py`의 `pct()`를 import해서 쓰세요. NULL을 보존합니다.

```python
from ..services.risk import pct
_pct = pct
```

라우터 4개(alerts / cells / compare / public)가 전부 이걸 씁니다.
사본을 두면 한쪽만 고쳐졌을 때 **같은 셀이 화면에 따라 "—"와 "0.00%"로 다르게** 뜹니다.

### CSV는 `lib/csv.js`를 쓰세요

`downloadCsv({ filename, subtitle, headers, rows, meta })`.
`meta`는 `/api/alerts/grade-notice` 응답을 그대로 넘기면 됩니다.

파일 맨 위에 기준 분기·등급 고지·잠정치 고지가 자동으로 붙습니다.
**이 파일은 화면을 떠나 회의자료로 돌아다니는데, 그때는 화면의 고지가 함께 있지 않습니다.**

값은 `csvNum()`을 통과시키세요. 화면과 같은 자릿수가 되고 없는 값은 빈 칸이 됩니다.

### 지도 색이 바뀌었습니다

백엔드가 내리던 색과 `index.css` 팔레트가 달라 폴리곤과 범례가 어긋나 있었습니다.

주의  #F59E0B → #dd5b00   (--accent-orange)

## 5. 새로 생긴 문구 원칙

### 분모가 다른 두 수를 슬래시로 묶지 마세요

```
쓰지 말 것   47곳 닫힘 / 전체 53곳
쓸 것        최근 4분기 연 293곳 중 47곳 닫힘 · 현재 점포 53곳
             또는   최근 1년 47곳 닫힘 · 현재 점포 53곳
```

눈으로 나눈 값이 큰 숫자와 4배쯤 어긋납니다.

### "판단보류"는 "안전"이 아닙니다

```
쓰지 말 것   데이터 없음
쓸 것        판단보류 — 표본이 충분한 업종이 5개 미만이라 등급 판정을 보류했습니다.
             위험하지 않다는 뜻이 아니라 판단할 근거가 부족하다는 뜻입니다.
```

### 비율 표시는 소수 1자리

폐업률 둘째 자리는 폐업 1건이 못 만드는 정밀도입니다(누적 분모가 수백 규모).
정보가 아니라 잡음이고, 화면 간 자릿수가 흔들리면 담당자가 다른 값으로 읽습니다.
