# 과거 관측 폐업률 입력 검증 결과 — 2026-09-03

**시점별 입력 복원·정답 완성 시점 분리를 구현했고, 과거 이탈률을 입력에 넣은
연구 모델도 실제로 학습했다.** 다만 추가 효과의 사전 판정 기준을 통과하지 못해
운영 모델·DB·추천점수는 교체하지 않았다.

[사전 계획](closure-history-validation-plan.md)을 고정한 뒤 같은 표본에서 기준
모델과 최근 1분기·4분기 관측 이탈률을 추가한 모델을 비교했다.
이 실험은 수요 자료나 외부 API 키를 사용하지 않는다.

## 바뀐 검증 방법

| 항목 | 이번 연구 파이프라인 |
|---|---|
| 스냅샷 | `store_panel.csv`의 실제 관측 817,741행만 사용. 후처리 보정 55,294행 제거 |
| 과거 보정 | 예측 시점까지 재등장이 확인된 1분기 공백만 보정. 이후 재등장으로 입력을 수정하지 않음 |
| 점포 수 | 해당 시점 실제 관측 점포 수 |
| 업력 대체 | 최신 인허가 업력 대신 당시까지의 최초 관측 후 기간. 실제 업력과 다름 |
| 추가 입력 | 같은 셀의 최근 1분기 이탈률 및 최근 4분기 건수합/직전 점포 수 합 |
| 정답 | 현재 점포가 2분기 뒤 화성시 전체 스냅샷에 없는 비율. 다른 셀로 이동한 동일 ID는 제외 |
| 정답 확정 | B+2 스냅샷 도착 후에만 사용. 최신 두 분기의 미확정 정답은 NaN 유지 |
| 범주형 처리 | 읍면동·업종 범주 목록도 학습 자료에서만 확정. 새 범주는 모델에 결측으로 전달 |

주소·좌표·기존 학습 정답·인허가 자료는 읽지 않았다. 식별자는 스냅샷 집합 비교를
위해 로컬 메모리에서만 사용했다. 산출 데이터는 읍면동×업종 집계이며 Git에 넣지 않는다.

합성 데이터의 미래 행 추가·변조 검사뿐 아니라 **실제 2024Q3·2025Q1 자료에서
전체 파일로 만든 입력과 해당 시점까지만 잘라 만든 입력이 정확히 같은지 확인했다.**
두 시점 모두 일치했다. 이는 구현의 시점 제한 검사이며 원본의 실제 발행일 인증은 아니다.

## 시간 분할과 공통 표본

| 구간 | 입력 분기 | 마지막 정답 확인 시점 | 행 수 |
|---|---|---|---:|
| 학습 | 2021Q4~2022Q4 | 2023Q2 | 1,758 |
| validation | 2023Q3~2023Q4 | 2024Q2 | 591 |
| test | 2024Q3~2025Q2 | 2025Q4 | 1,401 |

앞 구간의 정답이 완성된 다음에 뒤 구간의 예측이 시작된다. validation은 학습
조기 종료에만 사용하고 test로 가중치·입력·하이퍼파라미터를 고르지 않았다.
주 시험은 2024Q3·2025Q1이며 이후 두 분기 창이 겹치지 않는다.
2024Q4·2025Q2는 보조 결과로 보고한다.

고정 기간의 충분표본 3,822행 중 과거 입력 등이 완성되지 않은 72행을 제외해
두 모델 모두 같은 **3,750행**을 사용했다. 최신 미확정 3,616행은 학습/시험에서 제외했다.
학습에 없던 범주가 validation 1행, test 9행에 있었고 임의로 과거 범주에 합치지 않았다.
bootstrap은 범주 인코딩 전의 지역 식별을 보존해 새 지역도 빠뜨리지 않는다.

비교 모델은 같은 LightGBM 설정으로 새로 학습했다. **기존 운영 모델의 점수와
아래 성능을 직접 비교할 수 없다.** 입력의 업력 정의, 스냅샷 보정, 정답 정의가 다르다.
기준 모델은 읍면동·업종·점포 수·최초 관측 후 평균 기간을 사용하고,
추가 모델은 여기에 `closure_rate_1q`, `closure_rate_4q`를 넣었다.

## 결과: 과거 이탈률 추가 효과는 채택 기준 미달

Spearman과 lift는 높을수록 좋고, MAE는 낮을수록 좋다. 모든 정답률과 오차는
**스냅샷 미관측률**에 대한 것이다. 실제 폐업 확정률·창업 성공확률이 아니다.

| 시험 시점 | 셀 수 | Spearman 기준 → 추가 | lift 기준 → 추가 | MAE %p 기준 → 추가 |
|---|---:|---:|---:|---:|
| **2024Q3 (주 시험)** | 286 | 0.5245 → 0.5189 | 2.1372 → 1.8799 | 9.6977 → 9.7906 |
| 2024Q4 (보조) | 349 | 0.1505 → 0.1556 | 0.9126 → 0.9343 | 7.9221 → 7.7949 |
| **2025Q1 (주 시험)** | 384 | 0.5024 → 0.5144 | 1.0313 → 1.1871 | 9.7837 → 9.9466 |
| 2025Q2 (보조) | 382 | 0.4982 → 0.5038 | 1.1667 → 1.3228 | 10.5897 → 10.7713 |

| 주 시험 동일 가중 평균 | 기준 모델 | 과거 이탈률 추가 | 변화 |
|---|---:|---:|---:|
| Spearman | 0.5135 | 0.5167 | +0.0032 |
| 상위 10% lift | 1.5843 | 1.5335 | −0.0508 |
| MAE | 9.7407%p | 9.8686%p | +0.1279%p |

지역 단위로 같은 셀·시점을 함께 재표집한 1,000회 paired bootstrap의
‘추가 모델−기준 모델’ 95% 구간은 다음과 같다.

- Spearman: **−0.0319~+0.0266**
- lift: **−0.2208~+0.4027**
- MAE: **+0.0779~+0.1875%p**

두 주 시점 모두 순위·lift가 개선되어야 한다는 조건을 충족하지 못했고, 평균
오차도 커졌다. `directional_signal_passed=false`, `production_ready=false`다.
이 결과는 과거 폐업률이 언제나 쓸모없다는 결론이 아니라 **이번 데이터·정의·모델에서
추가 효과가 입증되지 않았다는 결과**다.

상위 10%는 사전 계획대로 90분위수 이상을 포함한다. 두 모델 모두 최적 반복수가
1로 선택돼 예측 동점이 많았다. 주 시험에서 선택 수는 기준 모델 57/286·57/384,
추가 모델 29/286·41/384다. 실제 선택 비율이 같지 않으므로 lift만으로
탐지 품질을 단정하면 안 된다. 결과를 본 뒤 동점 처리 규칙을 바꾸지는 않았다.

관측 4분기 이탈률만으로 정렬한 보조 기준선은 Q3/Q4/2025Q1/Q2 순서로
Spearman **0.2480/0.2672/0.6919/0.6233**, lift **0.9145/0.9884/2.8313/2.7679**다.
최근 시점에서 유용한 신호는 있지만 시점별 차이가 커서 전체 기간의 일관된 개선과 구분한다.
이 기준선은 확률 보정 모델이 아니므로 MAE를 비교하지 않았다.

## 학습이 초기에 멈춘 이유를 점검한 결과

두 모델 모두 validation으로 선택된 최적 반복수가 **1**이었다. 그대로 배포할 수 있는
완성 모델이라고 해석하지 않고, 시험 후 데이터 품질 진단을 추가했다.
진단 결과로 학습 행을 제외하거나 모델을 다시 고르지는 않았다.

공통 표본의 평균 정답률은 학습 **16.93%**, validation **8.30%**, test **12.93%**다.
학습의 2022Q3·Q4 입력은 각각 2분기 뒤 미관측률이 **31.54%·32.95%**로,
알려진 2023년 스냅샷 누락 시점과 연결된다. 이러한 분포 차이는 조기 종료를
해석할 때 고려해야 할 단서이며, 정확한 원인을 인과적으로 규명한 것은 아니다.

정답의 일시 누락 여부도 점검했다. **2024Q3 전체 점포 코호트**에서 B+2(2025Q1)에
없었던 5,954곳 중 **1,461곳(24.54%)**이 그 후 두 분기 안에 다시 등장했다.
이 값은 충분표본 평가 셀만의 통계가 아니라 전체 점포 코호트의 품질 진단이다.
2025Q1·Q2 입력은 정답 이후 두 분기 추적 자료가 부족해 재등장 비율을 계산하지 않았다.

따라서 ‘B+2에 없음’을 실제 폐업 확정으로 바꾸어 말하면 안 된다. 미래 재등장을
정답에 반영하고 싶다면 **그만큼 정답 확인 가능 시점도 뒤로 미뤄서** 시간 분할을
다시 설계해야 한다. 입력 누수를 막는 것과 정답의 의미를 정확히 정하는 것은 별도 문제다.

## 남은 조건과 현재 변경 범위

이번에 구현한 연구 파이프라인에서는 입력의 미래 참조와 시간 분할을 검사할 수 있다.
다만 실제 발행일 원장, 실제 폐업 확정 자료, 인허가 업력의 과거 버전은 확보하지 못했다.
자료는 이전 연구에도 사용됐으며 주 시험은 두 시점뿐이다.

운영 반영 전에 결정할 핵심은 **예측 대상을 스냅샷 이탈로 둘지, 더 긴 확인 기간이나
실제 폐업 이력으로 정답을 만들지**다. 전자를 택하면 서비스 설명도 그 의미에 맞춰야 하고,
후자를 택하면 정답 지연과 필요한 자료 기간이 늘어난다. 이번 결과만으로
운영의 기존 98.8점이나 공무원 위험등급을 바꾸지는 않았다.
