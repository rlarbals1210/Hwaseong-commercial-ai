# 인허가 폐업일로 정답을 보강한 결과

2026-09-03 · 연구용 검증 · 운영 모델/추천 산식/DB 변경 없음

## 판단

실제 폐업일을 연결해 정답을 비교하는 파이프라인을 구현했다. 소진공 미관측과
인허가상 폐업은 같은 사건이 아니며, 연결 표본에서도 차이가 크다. 인허가 정답으로
학습하면 폐업률 수준의 오차는 줄지만 **위험 순위 개선은 확인되지 않았다.**
새 모델의 MAE는 학습 평균을 모든 셀에 적용한 값과 거의 같았다.

이번 결과는 기존 모델이 검증됐다는 뜻도, 인허가 자료가 틀렸다는 뜻도 아니다.
정답 정의·연결 정확도·자료 갱신 이력·예측 입력을 더 검토해야 한다.
일반 교육에는 폐원 이력이 없으므로 남양읍 일반 교육 문제를 해결한 결과로 부르지 않는다.

## 원본 복원과 연결

소진공 2020Q4~2025Q4 ZIP 21개에서 식별 정보를 복원했다. 817,741행의
점포번호·분기·지역·업종이 기존 패널의 실제 관측 행과 정확히 일치했다.
보정으로 삽입된 행을 원본처럼 취급하지 않았다.

상호명+지점명과 도로명 건물주소 또는 지번주소가 정확히 일치하는 후보만 연결했다.
두 주소가 모두 있으면 서로 모순되지 않아야 하며, 양쪽에 층/호가 있으면 같아야 한다.
업종·인허가 기간을 확인하고 복수 인허가 및 같은 분기의 다대일 연결은 보류했다.
유사 이름 검색이나 주소만으로 연결하는 폴백은 없다.

| 연결 단계 | 건수 |
|---|---:|
| 전체 점포×분기 관측 | 817,741 |
| 이름·주소 후보가 있는 관측 | 225,513 |
| 업종까지 호환되는 후보가 있는 관측 | 199,882 |
| 주소 모순으로 제외한 후보 쌍 | 26,390 |
| 층/호 모순으로 제외한 후보 쌍 | 4,110 |
| 기준 시점의 영업 기간 밖인 후보 쌍 | 20,026 |
| 복수 인허가가 남은 관측 | 484 |
| 같은 인허가를 여러 점포가 공유한 관측 | 2,443 |
| 최종 유일 연결 관측 | 162,297 |
| 유일 연결 점포번호 | 17,267 |
| 두 정답을 함께 확인한 점포×분기 | 134,080 |
| 두 정답을 함께 확인한 점포번호 | 15,521 |

후보 쌍과 관측의 단위가 다르고 제외 사유가 겹칠 수 있어 각 행을 단순 차감하지 않는다.
정답이 함께 있는 134,080건은 결과 스냅샷이 있는 729,188건의 **18.39%**다.
동일 점포의 여러 분기가 반복되므로 독립 사업장 134,080개가 아니다.

정답 미확인 사유는 상태/날짜 불명확 10,896건, 행정자료 추적 시점 부족 10,291건,
소진공 결과 스냅샷 없음 7,030건이다. 이들을 0으로 채우지 않았다.

중요한 연결 한계도 확인됐다. 원본 소진공의 `호정보`는 전부 비어 있었고
양쪽 호수 일치를 확인한 연결은 **0건**이다. 상호명·건물주소·일부 층 일치는 확인했지만
같은 건물의 동명 사업장이나 명의 변경까지 배제했다고 주장할 수 없다.
현재 인허가 주소·이름을 과거에 연결하므로 이전·이름 변경을 거친 업체의 누락 편향도 있다.
독립 식별자나 사람의 검토를 통한 매칭 정확도 측정은 아직 없다.

## 정답은 무엇이 다른가

기준분기 B의 동일 연결 점포에 대해 다음 두 가지를 계산했다.

- **미관측 정답:** B+2의 화성시 전체 스냅샷에 점포번호가 없으면 1.
- **인허가 정답:** B 이후 B+2 분기말까지 명시적 폐업일자가 있으면 1.
  기준 시점에 영업 기간이 유효하고 상태·날짜가 일관되며 결과 시점까지 자료가
  갱신된 기록만 사용한다. 휴업·취소·말소·재개업 흔적은 보류한다.

인허가 0은 해당 기간에 등록된 폐업일이 없다는 뜻이다. 현재 정상 영업 기록을
활용하므로 과거의 모든 휴업/재개업 이력이 확인됐거나 현장 존속이 확인됐다는 뜻은 아니다.

전체 연결 비교 표본 134,080건의 결과:

| | B+2에 관측됨 | B+2에 미관측 |
|---|---:|---:|
| 인허가상 기간 내 폐업 기록 없음 | 120,332 | 7,212 |
| 인허가상 기간 내 폐업 기록 있음 | 911 | 5,625 |

미관측으로 1을 부여한 12,837건 중 **7,212건(56.18%)**은 인허가상 같은 기간의
폐업과 일치하지 않는다. 반대로 폐업일이 있는 6,536건 중 911건은 B+2 명단에 남아 있었다.
이는 **두 자료의 불일치율**이지, 현장 정답으로 확정한 오탐률이나 운영 모델의 오탐률이 아니다.
소진공 누락·명단 갱신 지연, 인허가 갱신 지연·누락, 연결 오류가 함께 영향을 줄 수 있다.

2023년 이상 구간에만 나타나는 현상도 아니다. 2024Q3 연결 관측 6,670건 중
미관측 560건의 281건, 2025Q1 연결 관측 8,651건 중 미관측 748건의 362건이
인허가 기간 내 폐업과 불일치했다. 이 표본은 아래 모델용 30개/50% 기준 적용 전 표본이다.

### 기존 운영 학습 원천의 갭필링 정답도 별도로 확인

모델 비교가 끝난 뒤 `store_labels.csv`의 실제 관측 행 `label_h2`도 동일 134,080건에서
대조했다. 이 정답은 전 기간 재등장을 사용하므로 아래 시간 분할 모델 학습에는 넣지 않았다.

| | 저장된 label_h2=0 | 저장된 label_h2=1 |
|---|---:|---:|
| 인허가상 기간 내 폐업 기록 없음 | 121,681 | 5,863 |
| 인허가상 기간 내 폐업 기록 있음 | 935 | 5,601 |

갭필링은 일부 불일치를 줄였다. 그래도 저장 정답 1의 11,464건 중
**5,863건(51.14%)**이 인허가 기간 내 폐업과 달랐다. 이 역시 **학습 정답끼리의 대조**이며
모델이 내놓은 예측이나 개별 상권의 위험등급에 대한 오류율이 아니다.

별도 사후 진단에서 폐업일이 있는 연결 5,865개 중 656개(11.18%)는 폐업일 이후 분기
명단에도 나타났다. 이 진단으로 연결이나 학습 표본을 사후에 다시 선택하지 않았다.

## 같은 표본에서의 모델 비교

결과 계산 전 고정한 [계획](permit-label-validation-plan.md)을 적용했다.
전체 점포 30개 이상, 두 정답 확인 점포 30개 이상, 확인 비율 50% 이상인 셀만 사용했다.
학습 263셀, 검증 72셀, 시험 230셀로 총 565개 **셀×분기**다.
한식·이용미용·기타간이·비알코올·중식·주점·일식·서양식 8개 업종이 남았다.
서양식 3셀은 학습에 없던 범주로 결측 범주 입력을 사용하되 평가에서 버리지 않았다.

- 학습: 2021Q4~2022Q4. 사건 창은 2023Q2까지.
- 검증: 2023Q3/Q4. 사건 창은 2024Q2까지.
- 시험: 2024Q3~2025Q2. 주 시험은 2024Q3·2025Q1 두 시점.
- 두 모델의 입력: 지역·업종·전체 점포수·최초 관측 후 기간·과거 1/4분기 관측 이탈률.
- 학습 정답만 동일 연결 점포의 미관측률/인허가 폐업률로 변경했다.
  두 모델 모두 **인허가 정답을 기준으로** 검증 조기종료와 시험 평가를 했다.
- 미래 폐업일·현재 인허가 영업상태·매칭 여부·확인 점포수는 모델 입력에 넣지 않았다.
  실제 2024Q3/2025Q1 입력은 미래 행 제거 전후 정확히 같았다.

주 시험 분기 지표의 동일 가중 평균:

| 지표 | 미관측 정답 학습 | 인허가 정답 학습 | 해석 |
|---|---:|---:|---|
| Spearman 순위 상관 | 0.1926 | 0.0895 | 악화 |
| 상위 10% lift | 1.0626 | 1.1658 | 불확실 |
| MAE | 5.3305%p | 2.5230%p | 오차 감소 |
| 최적 반복수 | 1 | 1 | 두 모델 모두 부스팅 1회가 최적 |

지역 클러스터 bootstrap 1,000회, 인허가 모델−미관측 모델 차이의 95% 구간:
Spearman **−0.2606~+0.0363**, lift **−0.1729~+0.3946**, MAE **−3.3403~−2.2897%p**.
순위 개선 조건을 통과하지 못했다.

| 시험 분기 | 셀 수 | 확인 점포 합계 | 평균 확인 비율 | Spearman 전→후 | lift 전→후 | 상위군 셀 수 전→후 |
|---|---:|---:|---:|---|---|---|
| 2024Q3 | 38 | 3,275 | 59.85% | 0.2456→0.0062 | 1.3775→1.2307 | 7→4 |
| 2024Q4 | 61 | 5,723 | 62.80% | 0.2487→0.1956 | 1.2015→1.2305 | 9→17 |
| 2025Q1 | 66 | 6,006 | 63.46% | 0.1396→0.1727 | 0.7477→1.1009 | 10→14 |
| 2025Q2 | 65 | 6,011 | 65.46% | 0.2609→0.2384 | 1.1951→1.1813 | 9→14 |

동점은 모두 포함해 상위군 크기가 다르다. 같은 수의 현장 확인 대상에 대한 효과로 해석하지 않는다.
표본·입력·정답이 바뀌었으므로 기존 운영 모델의 성능 수치와 직접 비교하지 않는다.

### 오차 감소가 AI의 유효한 학습인가

큰 MAE 개선을 그대로 성능 향상으로 오해하지 않도록 사후 참고 기준선을 추가했다.
학습 구간 인허가 폐업률의 셀 평균을 모든 시험 셀에 적용하면 주 시험 MAE는 **2.5291%p**다.
인허가 모델의 2.5230%p와 차이는 **0.0061%p**뿐이다. 이 기준선은 학습 표본만 사용했고
모델/정답/표본 선택에는 쓰지 않았다. 큰 오차 감소의 대부분은 정답의 평균 수준이 달라진
것으로 설명 가능하며, 상권별 위험 구분 능력이 확보됐다고 볼 수 없다.

## 적용 한계와 다음 판단

1. 현재 인허가 자료로 과거 날짜를 재구성한 회고 분석이다. 당시 공개/입수 가능했던 정답
   버전은 없다. 현재 영업상태와 주소를 이용한 표본 선택의 사후 편향이 남는다.
2. 소진공 파일의 실제 관측일과 발행일이 분리 검증되지 않았다. 특히 `20251031` 파일을
   기존 파이프라인과 같이 2025Q3으로 취급한다. 명목 분기 기준 비교이며 두 자료의 정확한
   달력상 관측 기간이 완전히 일치한다는 보장은 없다.
3. 확인 표본은 전체 성숙 관측의 18.39%이고 모델 평가에는 8개 업종만 남았다.
   일반 교육·부동산·대다수 소매업까지 일반화할 수 없다.
4. 데이터가 새로 생긴 것은 아니다. 기존 21개 분기를 다시 활용했고 이미 여러 번 분석한
   시험 기간이다. 새 독립 시험 및 매칭 정확도/행정자료 누락 검증이 필요하다.
5. 인허가를 날짜 기반 정답의 추가 근거로 활용할 가치는 확인했지만 **운영 모델 자동 교체는
   하지 않는다.** 다음 검토는 연결 오류·자료 시차를 확인하고, 인허가 업종에서 단순 평균보다
   위험 순위를 잘 구분하는 입력이 있는지 평가하는 것이다. 먼저 가중치부터 바꾸지 않는다.

새 연결/평가 테스트 18개와 기존 시점 검증 13개, 총 **31개 통과**.
동명이업체·주소/층/호 모순·빈 연결·복수 허가·영업 기간·정답 경계·상태 불확실·
추적 부족·공통 분모·표본 기준·시간 분할·평가 정답·미지 범주·미래 입력 불변성을 확인했다.
실제 전체 연결/학습/평가를 재실행해 연결 통계·정답 통계·두 모델 지표·bootstrap 결과가
모두 정확히 일치했다. 기존 matplotlib/pyparsing 경고 13건은 남아 있다.

`ai/permit_sources.py`는 원본 로더, `ai/permit_matching.py`는 연결·정답,
`ai/evaluate_permit_labels.py`는 비교 실행이다. 원본 ZIP의 목록/CRC/크기 및 인허가 파일
해시를 기록한다. 식별자가 있는 자료·연결표·연구 모델은
`data/processed/permit_label_audit/`의 Git 무시 경로에만 두며 외부 전송/커밋하지 않았다.
보고서의 숫자는 집계다. 운영 파이프라인·DB·공개 추천·공무원 화면은 이번 작업에서 수정하지 않았다.
