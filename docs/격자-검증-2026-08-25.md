# 격자 grain 검증 — 노다지식 지점 추천 이식 가능성

작성: 2026-08-25 / 대상: 리버스 노다지(화성시 소상공인 AI 정책지원 플랫폼)

## 결론

**기각.** 공간 해상도를 높여도 예측력이 늘지 않는다. 이 데이터에서 정보를 만드는 축은
위치의 정밀도가 아니라 **업종**이다. 노다지의 지점(spot) 추천은 이식하지 않는다.

---

## 1. 배경 — 왜 검토했나

서울 프로젝트('노다지')의 `/api/recommend/spot/`은 `location_scores.csv`(격자 사전계산)로
생존율·경쟁밀도·보완밀도·상권활력 4지표를 낸다. **이 네 지표가 전부 좌표만으로 계산되고
매출·유동인구가 들어가지 않아서**, 화성시로 넘어올 수 있는 몇 안 되는 후보로 보였다.

전제부터 확인했다. `CLAUDE.md`의 "원본 데이터가 집계 단위"는 **데이터 사실이 아니라
프라이버시 방침**이다. 실제 원본은 점포 단위이고, `data/processed/store_panel.csv`에
873,035행(2020Q4~2025Q4)의 점포별 경도·위도가 있다. 2025Q4 기준 44,287개 점포,
**좌표 결측 0건**. 격자 계산 자체는 지금 당장 가능하다.

## 2. 격자 커버리지 (2025Q4, 44,287개 점포)

| 격자 | 셀 수 | 중위 점포수 | n≥20 셀 | n≥20 커버율 |
|---|---:|---:|---:|---:|
| 250m | 3,826 | 2 | 423 | 72.3% |
| 500m | 1,839 | 4 | 342 | 84.1% |

현행 행정동×업종(`SAMPLE_MIN=50`)이 231셀 / 커버율 61.8%인 것과 비교하면 **커버리지는
격자가 넓다.** 여기까지만 보면 사각지대 문제(전체 점포의 38%, 16,901곳 제외)를 완화할
대안처럼 보인다. 그래서 예측력을 따로 검증했다.

## 3. 지속성 검증 — 과거 4분기 → 미래 4분기

`docs/modeling.md`·`CLAUDE.md`의 4분기 누적 전환 때 쓴 것과 같은 방식이다.
과거 창(2023Q3~2024Q2)의 단위별 `label_h2` 평균과 미래 창(2024Q3~2025Q2)의 평균을
스피어만 상관으로 비교하고, 과거 상위 10% 단위가 미래에 실제로 나쁜지를 리프트로 본다.
**모든 행을 같은 코드로 돌렸다** — 단위 정의만 바꿨다.

| 집계 단위 | 단위 수 | 스피어만 | 리프트 | Top10% 유지 |
|---|---:|---:|---:|---:|
| **행정동 × 업종 (현행, n≥50)** | 665 | **+0.422** | **1.41배** | 14/66 |
| 행정동 × 업종 (n≥30) | 886 | +0.413 | 1.56배 | 25/88 |
| 행정동만 (29개) | 29 | +0.319 | 1.06배 | 0/2 |
| 250m 격자 (n≥20) | 1,154 | +0.301 | 1.27배 | 24/115 |
| 250m 격자 (n≥50) | 562 | +0.252 | 1.10배 | 7/56 |
| 500m 격자 (n≥20) | 827 | +0.323 | 1.24배 | 19/82 |
| 500m 격자 (n≥50) | 462 | +0.274 | 1.19배 | 11/46 |
| 1000m 격자 (n≥20) | 477 | +0.321 | 1.30배 | 8/47 |
| 1000m 격자 (n≥50) | 322 | +0.334 | 1.14배 | 5/32 |

## 4. 해석

**(1) 공간 세분화의 한계효용이 0이다.** 행정동만 쓰면 +0.319인데, 250m까지 잘게 쪼개도
+0.301이다. 500m·1000m도 전부 +0.32 언저리에서 움직이지 않는다. 위치를 아무리 정밀하게
봐도 폐업 위험에 대해 새로 알려주는 것이 없다.

**(2) 정보는 업종 축에서 나온다.** 같은 행정동에 업종을 붙이는 순간 +0.319 → **+0.422**로
올라간다. 리프트도 1.06배 → 1.41배. 현행 grain이 옳았다는 사후 확인이기도 하다.

**(3) 표본 노이즈 문제가 아니다.** 250m에서 최소 표본을 20→50으로 올리면 상관이
+0.301 → **+0.252로 오히려 떨어진다.** 노이즈가 원인이라면 반대로 움직여야 한다.
표본이 큰 격자는 번화가라 서로 비슷해지고, 작은 격자는 폐업이 잘 없는 주택가라
"번화가 대 주택가" 구분만 남는 것으로 보인다 — 자리의 좋고 나쁨이 아니다.

## 5. 검증의 한계

- 미래 창(2024Q3~2025Q2)에 `docs/modeling.md` 3-2절의 **2024Q4 잔여 이상치**가 포함된다.
  갭필링으로 못 고친 구간이다. 다만 **모든 단위에 동일하게 걸리므로 상대 비교는 유효**하다.
  절대 수치는 보수적으로 볼 것.
- 라벨은 `label_h2`(관측분기 +2분기 폐업 여부), 갭필링 threshold=11 패널 기준.
- 격자는 경위도 등간격 근사(위도 0.00225 / 경도 0.00282 ≒ 250m)다. 투영 좌표계가 아니라
  화성시 위도대(37.03~37.29)에서만 유효하다. 결론을 뒤집을 만한 오차는 아니다.
- 단위 정의만 바꾼 단일 실험이다. 격자에 업종을 결합한 조합(격자×업종)은 셀이 훨씬
  희소해질 것으로 예상해 돌리지 않았다 — **확인 필요**로 남긴다.

## 6. 보고서·발표에서 쓰는 법

**가설 4로 편입한다.**

> "더 정밀한 위치로 내려가면 더 잘 맞힐 것이다" → **기각.**
> 정밀도는 공간이 아니라 업종에서 나왔다.

예상 질문 **"왜 읍면동 단위인가, 더 세밀하게 못 하나"**에 대한 답이 이 표다.
좌표 데이터가 없어서 못 한 것이 아니라, **있어서 해봤고 효용이 없어서 안 한 것**이다.
이 구분을 분명히 말할 것.

기존 가설 3개(라벨 재정의 / 표본 기준 상향 / 시민 조회 제외)와 같은 형식이다 —
해봤고, 틀렸고, 그래서 다음 행동이 바뀌었다.

## 7. 재현

`store_panel.csv`·`store_train_table.csv`만 있으면 SSD 없이 돌아간다.

```python
import pandas as pd
def sp(a, b): return a.rank().corr(b.rank())

df = pd.read_csv("data/processed/store_train_table.csv",
    usecols=["기준분기","경도","위도","label_h2","행정동명","상권업종중분류명"],
    dtype={"기준분기": str}).dropna(subset=["label_h2","경도","위도"])
qs = sorted(df.기준분기.unique()); P4, F4 = qs[-8:-4], qs[-4:]

def test(d, key, nmin, name):
    P = d[d.기준분기.isin(P4)].groupby(key).agg(n_p=("label_h2","size"), r_p=("label_h2","mean"))
    F = d[d.기준분기.isin(F4)].groupby(key).agg(n_f=("label_h2","size"), r_f=("label_h2","mean"))
    s = P.join(F, how="inner").query("n_p >= @nmin and n_f >= @nmin")
    if len(s) < 20: return
    k = max(1, len(s)//10); top = s.nlargest(k, "r_p")
    keep = len(set(top.index) & set(s.nlargest(k, "r_f").index))
    print(f"{name:<30} {len(s):>4}개 | 스피어만 {sp(s.r_p, s.r_f):+.3f} "
          f"| 리프트 {top.r_f.mean()/s.r_f.mean():.2f}배 | Top{k} 유지 {keep}/{k}")

test(df, ["행정동명","상권업종중분류명"], 50, "행정동x업종 (현행)")
test(df, ["행정동명"], 50, "행정동만")
for m, (a, o) in {250:(0.00225,0.00282), 500:(0.00450,0.00564), 1000:(0.00900,0.01128)}.items():
    d = df.assign(gid=(df.위도/a).astype(int).astype(str) + "_" + (df.경도/o).astype(int).astype(str))
    for nmin in (20, 50):
        test(d, "gid", nmin, f"{m}m 격자 (n>={nmin})")
```

## 8. 그래서 노다지에서 남은 것

격자가 빠지면 이식 후보는 전부 **현행 행정동×업종 grain 위에서** 돌아간다.
새 파이프라인도, 외장 SSD도 필요 없다.

| 기능 | 상태 | 비고 |
|---|---|---|
| 지역·업종 비교 | 가능 | `risk_index.csv`만으로 성립 |
| 상권 트렌드 | 가능 | 4분기 누적 창 이동. 단일 분기 비교로 만들지 말 것 |
| 행정동 → 업종 Top5 | 가능 | 위 표의 +0.422 / 1.41배가 근거 |
| 지점(격자) 추천 | **기각** | 이 문서 |
| 창업 비용 계산기 | 보류 | 임대료가 3그룹뿐(동탄권·병점권·경기광역) |
| 예상 매출 계산 | 불가 | 카드매출은 share만 사용 가능, 절대값 금지 |
