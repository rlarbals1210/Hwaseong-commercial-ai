# 수요 피처의 폐업 조기경보 증분 효과 실험

## 목적

과거 카드매출 수요 피처가 기존 셀단위 폐업률 모델의 순위 성능을 높이는지
방향성만 확인한다. 운영 모델·API·화면은 수정하지 않는다.

## 비교 조건

두 모델은 같은 행, 같은 시간 분할, 같은 LightGBM 설정을 사용한다.

- 기준 모델: 행정동, 업종, 평균 업력, 점포 수
- 수요 추가 모델: 기준 모델 + 수요공급 격차 + 최근 3개월 수요 모멘텀
- 학습: 2022Q1·Q2·Q4, 2023Q1
- 검증: 2023Q2
- 시험: 2025Q1·Q2
- 점포 수 30곳 이상 셀만 사용

실행:

```bash
python ai/evaluate_demand_closure_ablation.py
```

결과는 `data/processed/demand_closure_ablation_results.json`에 저장한다.

## 실행 결과

점포 수 30곳 이상인 동일 셀 2,585행으로 비교했다. 시험 구간은 2025Q1·Q2의
797행이다.

| 지표 | 기준 모델 | 수요 추가 모델 | 변화 |
|---|---:|---:|---:|
| Spearman | 0.2717 | 0.2581 | -0.0136 |
| 상위 10% lift | 1.1570 | 1.1689 | +0.0119 |
| MAE | 0.06557 | 0.06496 | -0.00061 |

MAE와 lift는 소폭 좋아졌지만 핵심 순위 지표인 Spearman은 두 시험 분기에서
모두 하락했다. Spearman 변화의 행정동 클러스터 부트스트랩 95% 구간도
-0.0489~0.0225로 0을 포함한다. 따라서 방향성 게이트는 실패했으며, 현재 수요
피처를 폐업 조기경보 모델에 넣을 근거가 없다.

## 판정 원칙

전체 시험 구간의 Spearman과 상위 10% lift가 모두 좋아지고, 행정동 클러스터
부트스트랩 95% 구간의 하한도 0보다 크며, 두 시험 분기 모두 Spearman 개선이
나타날 때만 `directional_signal_passed=true`로 둔다.

이 조건을 통과해도 운영 반영 조건은 충족되지 않는다. 수요 피처가 있는 분기가
7개뿐이고 검증 분기도 하나이며 2023Q2와 2025Q1 사이에 긴 결측 구간이 있기
때문이다. 최소 12개 연속 분기와 기존 운영 검증 구간의 2개 이상 분기를 확보한
뒤 현재 운영 분할로 다시 비교해야 한다.

## 대체 데이터 조사

- `경기도 분석 카드매출 요일별`: 행정동×업종 구조지만 공개 Sheet에서 확인되는
  기준년월은 2022-01이며 2024년 결측 대체 자료가 아니다.
- `경기도 분석시스템 카드매출 시간대별`: 행정동×시간대×업종 구조이고 원본 ZIP은
  353MB다. 다만 공식 포털 로그인 없이는 다운로드가 차단되고 공개 Sheet는
  2020-03 샘플만 보여 실제 2024년 포함 여부를 확인하지 못했다.
- 시군구 단위 카드매출 자료는 행정동 간 수요점유율을 만들 수 없어 대체 후보에서
  제외한다.

따라서 현재는 결측을 임의 보간하거나 서로 다른 자료를 이어 붙이지 않는다.
