## 2. 뭐가 바뀌었나 — 한 줄 요약

**모든 지표를 "한 분기"에서 "최근 4분기 누적"으로 바꿨습니다.**

한 분기만 보면 점포 60곳짜리 상권에서 폐업 1~2건 차이로 폐업률이 1.5%와 9.0%를 오갑니다.
그래서 이런 일이 벌어지고 있었습니다.

| 문제 | 실측 |
|---|---|
| 분기마다 위험 순위가 거의 다 바뀜 | Top10 유지 **1.0개 / 10** |
| 등급 기준선이 3배 요동 | 위험 기준 6.00% ~ 18.76% |
| 작은 상권이 상위권 점거 | 상위 8개가 전부 점포 54~84곳 |

4분기 누적으로 바꾸니 **Top10 유지 1.0개 → 5.4개**, 순위 상관 +0.296 → +0.857이 됐습니다.

> "신호가 느려지는 것 아니냐"는 걱정은 실측으로 반박됐습니다.
> 과거 N분기로 미래 폐업률을 예측할 때 상관이 1분기 +0.319 / 4분기 +0.345 / 8분기 +0.501로,
> **긴 창이 오히려 미래를 더 잘 맞힙니다.** 급변은 대부분 평균으로 되돌아옵니다.

## 3. 코드를 만지는 사람 — Breaking Change

### API 응답 필드가 바뀌었습니다

`GET /api/alerts/closure-risk` 응답에서

```
삭제됨   actual_closure_rate_pct
추가됨   cumulative_closure_rate_pct   최근 4분기 누적 폐업률
         cumulative_closure_count      같은 창의 폐업 건수
         store_count                   전체 점포 수
         confidence_lower_pct          신뢰하한
         risk_grade                    등급
         cell_type                     상권 유형
         cell_type_summary/advice/avoid  유형별 처방 문구
         quarter_closure_rate_pct      단일 분기(참고용)
```

`GET /api/alerts/closure-rate-ranking`의 `closure_rate_pct`는 **이름은 같지만 의미가 바뀌었습니다**
(단일 분기 → 4분기 누적). `industry_rank` / `industry_total`도 추가됐습니다.

`GET /api/alerts/grade-notice` 신규 — 기준선과 고지 문구를 내려줍니다.

### 프론트에 숫자를 하드코딩하지 마세요

`DashboardPage.jsx`에 `CITY_AVG_PCT = 3.22`가 박혀 있었습니다. 파이프라인을 다시 돌려
평균이 5.9%가 됐는데 **화면은 계속 3.22%라고 말하고 있었습니다.**

이제 `/api/alerts/grade-notice`에서 받습니다. 다른 화면에서도 같은 방식으로 쓰세요.

### 아직 안 고친 화면

**`MapPage.jsx`와 `PolicyPage.jsx`는 그대로입니다.** 지도는 동 단위 요약을,
현장점검은 4사분면을 쓰고 있어 별도 판단이 필요합니다. 손대실 분은 먼저 얘기해주세요.

## 4. 새로 생긴 것 — 상권 유형 4분류

지금까지 위험도 한 축뿐이라 어느 셀이든 결론이 "현장 확인" 하나였습니다.
개업률 축을 얹어 같은 "위험"이라도 처방이 갈리게 했습니다.

| 유형 | 상태 | 처방 |
|---|---|---|
| **고회전** | 폐업↑ 개업↑ | 창업 사전상담, 업종 과밀 관리 (개별 자금지원은 상권 단위에서 상쇄) |
| **쇠퇴** | 폐업↑ 개업↓ | 상권 활성화, 시설·환경 개선 — **진짜 위험** |
| **성장** | 폐업↓ 개업↑ | 과열 조짐 관찰만 |
| **정체** | 폐업↓ 개업↓ | 신규 유입 유도 |

검증에서 고회전 비중이 **동탄7동 70% / 동탄4동 67% / 동탄9동 60%**로 신흥개발지에 몰리고
**서신면·우정읍·팔탄면은 0%**로 나왔습니다. 기존에 잡아둔 "최근 개발지 vs 성숙 상권" 구도와 맞습니다.

### 문구 톤 — 발표·보고서에서도 지킬 것

"고회전 상권에는 개별 자금지원 효과가 낮다"는 판단은 그대로 살리되, **부정문을 쓰지 않고
주어를 상권 구조로** 둡니다. 화성시가 잘못하고 있다는 인상을 주면 안 됩니다.

```
쓰지 말 것   "개별 자금지원 효과가 낮습니다"
쓸 것        "개별 점포 지원의 효과가 상권 단위에서는 상쇄될 수 있어,
              창업 사전상담과 업종 과밀 관리를 먼저 검토하시길 권장합니다"
```

## 5. 보고서·PPT 쓰는 사람 — 수치 갱신

| 항목 | 옛 값 | 새 값 |
|---|---|---|
| 셀 모델 스피어만 | 0.4193 | **0.4184** |
| 상위 10% 리프트 | 1.444x | **1.433x** |
| 모델 feature 수 | 5개 | **4개** (임대료_매핑그룹 제거) |
| 화성시 평균 폐업률 | 3.22% (분기) | **5.9%** (4분기 누적) |
| 위험 기준 | 6.44% | **10.35%** (상위 10%) |

### 반드시 지킬 것

**등급은 절대 기준이 아니라 화성시 내 상대 순위입니다.**
위험 = 상위 10%, 주의 = 상위 30%. 보고서·발표·화면 어디서든 이 점을 명시하세요.

고정 임계값을 안 쓴 이유는 이렇습니다. 2025년 폐업이 평시의 1.85배인데
**데이터 결함인지 실제인지 판정이 불가능**합니다(과거 같은 패턴 2건은 3~4분기 뒤 재등장으로
결함이 확인됐고, 2025년분은 아직 관측 기간이 부족합니다).
고정 기준을 쓰면 그 미확인 급증이 그대로 "위험 셀 85개"라는 정책 판단이 됩니다.

**그래서 발표에서 "화성시 폐업이 최근 급증한다"를 근거로 쓰면 안 됩니다.**
대신 지역 간 격차를 근거로 쓰세요.

## 6. 발표에 쓸 만한 발견

**학원가가 점포의 14.9%인데 폐업의 28.8%를 차지합니다.**

위험 등급 24개 중 18개가 교육 계열이었습니다. 데이터 결함을 의심했는데,
인허가 매칭률이 교육 90.2% vs 나머지 80.3%로 **오히려 교차검증이 더 잘 되는 업종**이었습니다.
실제 현상입니다.

단일 분기 방식에서는 노이즈에 가려 위험 23개 중 교육이 1개뿐이었습니다.
**4분기로 묶으니 드러난 것**입니다.

목록이 학원으로 덮이지 않도록 `industry_rank`(업종 내 순위)를 함께 내려줍니다.
