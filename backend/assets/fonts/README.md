# PDF 한글 글꼴

나눔고딕 Regular/Bold 원본 TTF를 포함한다. PDF에 사용한 글리프를 포함해 서버나 독자의 OS에 글꼴이 없어도 한글이 표시되고 검색·복사가 가능하다. 실행 중 외부 폰트 요청은 하지 않는다.

- 출처: [Google Fonts / Nanum Gothic](https://github.com/google/fonts/tree/main/ofl/nanumgothic)
- 라이선스: 함께 보관한 `OFL.txt` (SIL Open Font License 1.1)
- 원본을 수정하거나 이름을 변경하지 않았다.

- Bold SHA-256: `f96298f9fb18e364d2370f4c3ce948ac67a2b61af992d7234bc15c42b033c674`
